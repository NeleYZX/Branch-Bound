Interpretation notes:
- Each (n_parts, instance_id) forms one block; sixteen parameter configurations per block.
- The size main effect is subsumed in the instance fixed-effect blocks.
- All OPTIMAL runs outrank every TIME_LIMIT run within the same instance.
- Search time is used only for OPTIMAL runs; MIP gap is used only for TIME_LIMIT runs.
- The gap-aware RDI is rank-based, so it preserves ordering rather than the magnitude of time or gap differences.
- Normal-error ANOVA p-values are approximate; the Friedman test cross-checks overall treatment differences.
- Each instance-by-configuration cell contains one CPU time; no independent stochastic repetitions are present.
- Statistical significance does not prove a configuration is uniformly fastest across sizes.
- Higher-order effects by size are exploratory with only 3 instances per size.
- The data do not contain independent repeated solver seeds for a given instance/configuration.
