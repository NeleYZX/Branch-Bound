# 两项实验对比分析

使用用户指定目录的 BB_Basic_数据分析.xlsx（七列数据）与 TT_1D_Gurobi.xlsx 的 TT_1D 工作表；按n、TF、RDD配对48例。small工作表属于另一组实例，不纳入。

## 3. TF=RDD=0.6：算法效率

- n=10–20，BB记录运行时间均低于Gurobi；n=21两者均约3600秒。
- BB在n=10–20的最优解列有值；Gurobi在n=10–14明确标opt.，n=15、16、18虽未标opt.但gap≤0.1%。
- n=21时BB最终gap约81.11%，Gurobi约70.65%。达到时间上限后，Gurobi报告的gap更小；不能只依据小规模耗时推断所有规模均占优。
- 两方法未保证相同停止精度，且BB的runtime为搜索耗时；运行时间曲线不直接等价于同精度的完整求解加速比。

## 4. TF、RDD各取0.3/0.6：问题参数影响

- TF=0.3、RDD=0.3：BB平均gap 15.86%；Gurobi平均gap 19.17%；Gurobi gap≤0.1% 为 9/12。
- TF=0.3、RDD=0.6：BB平均gap 16.67%；Gurobi平均gap 3.68%；Gurobi gap≤0.1% 为 11/12。
- TF=0.6、RDD=0.3：BB平均gap 6.22%；Gurobi平均gap 18.67%；Gurobi gap≤0.1% 为 8/12。
- TF=0.6、RDD=0.6：BB平均gap 6.76%；Gurobi平均gap 18.52%；Gurobi gap≤0.1% 为 8/12。

- 本批记录中，TF=0.6的两个组合BB平均gap较小；TF=0.3、RDD=0.6时Gurobi平均gap较小。参数影响应结合相同n的耗时与gap一起查看。
- 每种规模与参数组合只有1例，以上为描述性结果；不作因果与显著性结论。

## 必须核对的数据差异

两条记录在双方都报告最优时目标值不一致，尚不能确认完全同一实例/模型：
- n=16、TF=0.6、RDD=0.3：BB=206.55019519999993，Gurobi=206.5486807813736。
- n=19、TF=0.3、RDD=0.6：BB=291.74097119999993，Gurobi=103.90790399999996。

尤其n=19、TF=0.3、RDD=0.6差异很大；第4项结论应视为暂定，待核对输入实例、目标函数与模型约束后用于正式实验结论。
