# BB 与 Gurobi 对比分析（现有BB配置，待确认最佳设置）

## 比较范围

- 使用 TT_1D 工作表，匹配 n、TF、RDD，共48对，n=10–21；Gurobi n=5的4例因缺少BB结果不纳入。
- small 工作表不是同一批实例：例如n=10、TF=RDD=0.6目标值124.7808704，与TT_1D及BB的116.3003072不同，因此不混用。
- 第3项对应 TF=RDD=0.6 两张专图；第4项暂按TF、RDD各取0.3/0.6的全部四种组合处理。

## 配置与可比性

- BB来源：Journal article/BB_Basic/basci.csv，αser=0、αpos=0.2。历史BB日志记录节点策略为Hybrid (Best-first + DFS)，但尚无证据说明其为比较试验中最佳策略。
- 调参汇总使用16part_1等不同实例；不能逐实例挑选最快参数混合成“最佳BB”。最佳配置需用统一选定的参数及节点策略的独立测试结果。
- 主耗时图采用BB solver_call_seconds，并辅以search_time_seconds；Gurobi采用t_run(s)。硬件、线程数、计时范围及停止容差尚未核实，因此仅作为记录耗时比较。
- BB时间上限约束搜索阶段，调用总耗时可超过3600秒；Gurobi也有耗时未到3600秒但gap>0的记录，不能把所有空opt.状态视为超时。
- Gurobi仅opt.字符串视为明确最优，另列gap≤0.1%的近优覆盖率。极小正gap不自动重写为精确最优。
- 严格配对耗时比只纳入双方均明确最优且目标值在相对1e-6/绝对1e-5内一致的记录；未最优实例不计算精确求解加速比。
- 最终gap保留各自定义；未核实Gurobi的gap分母与BB是否一致。

## 结果概览

- TF=0.3、RDD=0.3：BB明确最优 10/12，Gurobi opt.标记 6/12，Gurobi gap≤0.1% 9/12；平均gap BB 15.86% / Gurobi 19.17%。
- TF=0.3、RDD=0.6：BB明确最优 10/12，Gurobi opt.标记 7/12，Gurobi gap≤0.1% 11/12；平均gap BB 16.67% / Gurobi 3.68%。
- TF=0.6、RDD=0.3：BB明确最优 11/12，Gurobi opt.标记 5/12，Gurobi gap≤0.1% 8/12；平均gap BB 6.22% / Gurobi 18.67%。
- TF=0.6、RDD=0.6：BB明确最优 11/12，Gurobi opt.标记 5/12，Gurobi gap≤0.1% 8/12；平均gap BB 6.76% / Gurobi 18.52%。

## 结论边界

- 优先结合耗时与最终gap评价效率：耗时短但剩余gap高，不能视为同等求解质量下更高效。
- 参数影响应在相同规模下横向比较；各组合每个规模只有一个实例，无重复试验，不作显著性或因果结论。
- 这套图可用于现有BB配置的初步比较；在确认最佳α参数和节点策略前，不应作为“最佳BB vs Gurobi”的最终论文结论。
